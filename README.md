# EPOC

## Project discription

A project to investigate neurophysiological correlates of Post-COVID Symptoms by the means of EEG.

## Supervisors

* Prof. Dr. med. Walter Maetzler
* Dr. Julius Welzel
* Prof. Dr. Julian Keil

## Folder structure



* 01\_data *(raw data in BIDS Format can bew downloaded at OpenNeuro: )*
* 02\_scripts *(code to process and evaluate the data)*
* 03\_figures *(graphical representations of data processing and results)*
* 04\_software *(software used for EEG processing - fieldtrip 20250106 and EEGLAB 2024.2)*
* BC-128-pass-lay.mat *(contains 2D and 3D positions of the electrodes of the cap that was used. Necessary to visualize data)*
* environment.yml *(contains the version of python that was used and the necessary packages)*
