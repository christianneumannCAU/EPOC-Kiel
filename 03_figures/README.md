* **01\_bad\_trials\_z\_pvt**		: Plots of z-scores of all trials for each participant in PVT. Used to remove trials before ICA (EPOC\\02\_scripts\\s01\_badChannelsAndICA)
* **02\_ica\_plots\_pvt** 		: Topography plots for each participant showing good and noisy ICA components in PVT in seperate files (with IC-label in (EPOC\\02\_scripts\\s01\_badChannelsAndICA))
* **03\_fooof\_pvt**			: Plots of aperiodic component and oscillatory power in PVT (before and after stimulus) for every participant after using specParam (03\_scripts\\02\_scripts\\s02\_aperiodic\_power)
* **04\_alpha\_peak\_pvt**		: Powerspectra highlighting the alpha band and its peak (03\_scripts\\02\_scripts\\s02\_aperiodic\_power)
* **05\_theta\_peak\_pvt**		: Powerspectra highlighting the theta band and its peak (03\_scripts\\02\_scripts\\s02\_aperiodic\_power)
* **06\_eeg\_peaks**			: Graph showing changes from pre- to post-Stimulus for alpha and theta (03\_scripts\\02\_scripts\\s06\_pre\_post\_increase\_eeg), topography plots (03\_scripts\\02\_scripts\\s08\_topoplots\_beforeafter\_groups), and  time-frequency representation (03\_scripts\\02\_scripts\\s09\_TFR\_plots)
